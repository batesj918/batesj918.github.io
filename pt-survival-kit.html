PT Survival Kit

A three-tool digital bundle that helps physical therapists push back on burnout.

Role
Solo: concept, build
Status
Pre-launch
Platform
Web landing page
Checkout
Gumroad

The three tools in the bundle. The landing page isn't public yet, so this illustrates its contents.

The challenge

Physical therapists are burning out under documentation, required continuing-education (CEU) credits and the pressure to keep up with research. As a recruiter hiring PTs day to day at Professional Therapy Partners, I see this firsthand.

What I built

A one-time-purchase bundle of three digital tools, each aimed at one of the biggest daily stressors. It is sold through a conversion-focused landing page that walks visitors from the problem to the tools, how they work and bundle pricing.

Results

  • Fully built, mobile-responsive landing page: hero, problem, solution, how it works, pricing.
  • Value-stack offer: $87 of tools for $49, with Gumroad checkout and instant download.
  • One listing away from launch.

Built with

  • React + TypeScript
  • Vite
  • Tailwind CSS v4
  • Radix UI / shadcn/ui
  • Express
  • Drizzle
  • Gumroad

Features 7 total

The three tools

  • Burnout Reset Planner: printable and digital weekly planner, a daily top-3 priorities system, documentation time blocks and boundary scripts
  • No-BS CEU Finder: curated, affordable, commonly accepted CEUs with online and live options, ethics-requirement filters, cost comparisons, and notes and ratings
  • Evidence Survival Kit: plain-language research summaries (what the evidence supports and what it doesn't), patient talking points and insurance rebuttal scripts

Landing page + offer

  • Built as six sections: hero → problem → solution → how it works → pricing → footer
  • Value-stack pricing: $87 in separate tools offered as a $49 bundle
  • Gumroad checkout with instant digital download and lifetime updates
  • Mobile-responsive, accessible component library (Radix / shadcn)
